# AudioSamples

`synthetic_voice_445_458.wav` is a generated harmonic smoke-test signal included only to prove the tool chain works. It is not representative of real speech quality.

For the useful comparison, copy your own 48 kHz, mono, signed 16-bit PCM WAV here and run:

```bash
./Tools/compare_autotune.sh AudioSamples/voice.wav
```
